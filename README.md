This project is a hands-on introduction to Natural Language Processing (NLP) for text classification. The goal is to accurately classify SMS messages as spam or ham (not spam) using two foundational NLP techniques:

Bag of Words (BoW)

TF-IDF (Term Frequency-Inverse Document Frequency)

We leverage Python's nltk and scikit-learn libraries and train a Multinomial Naive Bayes (MultiNB) model for classification.
